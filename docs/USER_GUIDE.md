# Panduan Pengguna

1. **Masuk** di `login.html` (atau daftar bila administrator mengaktifkan pendaftaran). Lupa password? Pakai *Lupa password* — tautan reset dikirim ke email.
2. **Dashboard** — ringkasan akun, jumlah pemeriksaan, pemeriksaan & rekomendasi terakhir, grafik riwayat.
3. **Pemeriksaan baru** — isi 7 parameter dengan satuan dan rentang yang tertera: N, P, K (mg/kg), suhu (°C), kelembapan (%), pH, curah hujan (mm). Koma atau titik dapat dipakai sebagai desimal. *Reset* mengosongkan form; *Periksa dan Rekomendasikan Tanaman* mengirim.
4. **Hasil** — tanaman rekomendasi, kandidat teratas dengan probabilitas, nilai masukan, tanggal, ID, versi model. Tombol: Cetak, Download PDF (dialog cetak → simpan PDF), Lihat riwayat, Pemeriksaan baru. *Ini rekomendasi berbasis data, bukan jaminan panen; pertimbangkan kondisi lapangan.* Bila ada nilai di luar rentang data latih, hasil ditandai kurang andal.
5. **Riwayat** — cari, filter tanggal & tanaman, halaman, detail, PDF, hapus milik sendiri. Anda tidak dapat melihat data pengguna lain.
6. **Profil** — ubah nama; ganti password (password lama diperlukan). Role tidak bisa diubah sendiri.
7. **AI Assistant** — tanya tentang tanah, iklim, atau hasil rekomendasi. Pesan diproses layanan AI pihak ketiga: jangan kirim data pribadi. Anda dapat mencentang izin agar AI membaca data satu pemeriksaan (tanpa data pribadi). Jawaban AI adalah saran umum, terpisah dari hasil model ML, dan dapat keliru. Ada batas pesan harian; bila kuota habis Anda akan melihat pesannya.
